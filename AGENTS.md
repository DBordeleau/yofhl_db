# YOFHL database

## Agent skills

Read these before the first write of a session.

- **Issue tracker**: GitHub Issues on `DBordeleau/yofhl_db`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.
- **Labels**: `needs-planning`, `ready-for-implementation`, `spec`, `ticket`, beside the issue-type labels. See `docs/agents/labels.md`.
- **Conventions**: attribution, branch names, commits, cleanup, effort. See `docs/agents/conventions.md`.
- **Domain docs**: single-context, one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
- **Environment**: shell, dev server, checks. See `docs/agents/environment.md`.

The workflow these support lives in [DBordeleau/skills](https://github.com/DBordeleau/skills). Change the skills there, and the per-repo config here.
